🧩 ส่วนที่ทำ “เหมือน HMS” คงของเดิม

  • หัวฟ้าโค้ง + รูป/ชื่อ/ตำแหน่ง + ไอคอนสแกน & กระดิ่ง (จุดแดงเมื่อมีแจ้งเตือน)
  • เมนูลัด 5 ปุ่ม — ข้อมูลพนักงาน · โควตาการลา · จัดการเวลา · ยื่นเอกสาร (มี badge) · อนุมัติเอกสาร
  • การ์ดข้อมูลประจำวัน — วันที่ไทย, กะ 08:00–12:00–13:00–17:00, เวลาเข้า/ออก
  • News Feed — การ์ดอนุมัติเอกสารของลูกทีม พร้อมรูป ผู้ขอ ประเภท ช่วงวัน หมายเหตุ สถานะ
  • แถบล่าง 5 ช่อง + ปุ่มสแกนวงกลมกลาง (เปลี่ยนลายนิ้วมือ → สแกนหน้า)

⭐ แนะนำให้เพิ่ม ของใหม่

ฟีเจอร์ทำไมถึงควรมี (อ้างอิงข้อมูลจริงของบริษัท)
🔔 เตือนก่อนลืมลงเวลาออก ในรายงานขอเอกสาร “ลืมลงเวลา/เพิ่มเวลา” เป็นประเภทที่เจอบ่อย → เด้งเตือนตอนใกล้เลิกกะถ้ายังไม่มี OUT ตัดต้นตอปัญหาได้เลย
⏳ กันยื่นย้อนหลังนาน ข้อมูลจริงมีคนยื่นย้อนหลัง 13–14 วัน → เตือน/ต้องมีเหตุผลเมื่อเกิน X วัน และโชว์ตัวเลข “ย้อนหลังกี่วัน” ให้ผู้อนุมัติเห็น
👁 ตรวจว่าเป็นคนจริง (liveness) สแกนหน้าอย่างเดียวถ่ายรูปจากรูปได้ → ให้กะพริบตา/หันหน้า กันสแกนแทนกัน
📍 บอกระยะห่างจากจุดที่อนุญาต HMS เก็บพิกัดอยู่แล้ว แต่รายงานโชว์ “สถานที่ = 0” → แสดงเป็นเมตร + ถ้านอกพื้นที่ให้ติดธงรออนุมัติ
📶 ลงเวลาแบบออฟไลน์ คลัง/หน้างานสัญญาณไม่ดี → เก็บในเครื่องก่อน ส่งอัตโนมัติเมื่อมีเน็ต (กันลืมลงเวลาซ้ำ)
📊 สรุปเดือนปัจจุบันในหน้าแรก ทำงานกี่วัน / ลา / ขาด / พักร้อนคงเหลือ — พนักงานเห็นเองก่อนสิ้นเดือน ลดการทักท้วงตอนจ่ายเงิน
✅ อนุมัติทีละหลายใบ + ดูรูปสแกน หัวหน้ามี badge 999+ → ให้กดอนุมัติเป็นชุด และเปิดดูรูป/พิกัดตอนสแกนประกอบการตัดสินใจ
🔁 เตือนสแกนไม่ครบคู่ รองรับ IN/OUT ได้ถึง 5 คู่/วัน (ตามไฟล์จริง) → ถ้าคู่ไม่ครบให้เตือนทันทีในวันนั้น ไม่ต้องรอปิดงวด

⚠️ ข้อจำกัดที่ต้องรู้ก่อนลงมือ

Open API ของ HumanSoft อ่านได้อย่างเดียว (ทดสอบชื่อ action ตระกูลเขียน 26 แบบ + path อื่น 8 แบบ = ไม่มีเลย) → แอปนี้ ส่งเวลากลับเข้า HumanSoft เองไม่ได้
