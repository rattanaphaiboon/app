UI กลางของบริษัท ใช้ได้ทุกแอป

ใส่ไฟล์ CSS และ JS สองบรรทัด แอปใหม่ก็ได้หน้าตาพรีเมียมแบบเดียวกันทั้งบริษัท ทั้งโหมดสว่างและโหมดมืด ภาษาไทยและอังกฤษ

เริ่มใช้งาน ดูคอมโพเนนต์

เริ่มใช้งานใน 3 ขั้นตอน

วางไฟล์ไว้ที่เดียว (เช่น GitHub Pages ของบริษัท) แล้วทุกแอปลิงก์มาใช้ร่วมกัน แก้ที่เดียว เปลี่ยนทุกแอป

1ใส่ 2 บรรทัดใน <head>

rattana-ui.css (สี ฟอนต์ คอมโพเนนต์) และ rattana-ui.js (ธีม ภาษา toast ยืนยัน)

2ใส่ rt-app และพื้นหลัง

body class="rt-app" และ div.rt-bg ไว้บนสุด จะได้แสงพื้นหลังแบบคริสตัลทันที

3คัดลอกคอมโพเนนต์

กด “คัดลอกโค้ด” ในหัวข้อด้านล่าง แล้ววางในหน้าของคุณ

Toast และหน้าต่างยืนยัน (JS)

// ยืนยันก่อนทำรายการสำคัญ
RattanaUI.confirm({ title: 'อนุมัติคำขอนี้หรือไม่?', message: 'บันทึกแล้วแก้ไขไม่ได้', variant: 'approve', confirmText: 'ยืนยันอนุมัติ' })
  .then(ok => { if (ok) RattanaUI.toast('อนุมัติเรียบร้อยแล้ว'); });

RattanaUI.toast('บันทึกไม่สำเร็จ', { type: 'error' });
RattanaUI.setLoading(button, true);          // ปุ่มหมุนรอ

RattanaUI.formatMoney(1234.5);               // ฿1,234.50
RattanaUI.setTheme('dark');  RattanaUI.setLang('en');

กฎที่ทุกแอปต้องทำตาม

วันที่อยู่ซ้ายบนทุกหน้า/ทุกส่วนที่มีวันที่ วางไว้ก่อนหัวข้อ ห้ามไว้ขวาบน
เขียว = อนุมัติ · แดง = ไม่อนุมัติปุ่มทองใช้กับงานทั่วไป ไม่ใช้แทนปุ่มยืนยัน
สถานะมีคำ + ไอคอนเสมอไม่ใช้สีอย่างเดียวในการสื่อความหมาย
ข้อมูล 2 บรรทัดข้อมูลหลักบน รายละเอียดเล็กล่าง แทนการเพิ่มคอลัมน์
ติดป้ายข้อมูลตัวอย่างข้อมูลสมมติต้องมีป้าย “ข้อมูลตัวอย่าง” ทุกครั้ง
โลโก้ใช้ไฟล์จริงเท่านั้นห้ามวาดใหม่ เปลี่ยนสี ยืด หรือใส่เอฟเฟกต์
