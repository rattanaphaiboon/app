📌 3 ขั้น — ① หัวหน้างานกรอกคำขอในชีต (แท็บ ขอปรับเงินเดือน / สวัสดิการ / ใบเตือน / ตกเบิก / ปรับผ่านงาน) — ขึ้นคิวทันทีไม่ต้องรอ approve (มีป้ายสถานะบอก) → ② กด 👁️ ตรวจ & ออกเอกสาร ระบบตรวจข้อมูลให้ (✅ ⚠️ ❌) พร้อมตัวอย่างเอกสาร → ③ กด ✔ ออกเอกสาร ระบบรันเลขที่ บันทึกลงแท็บ สรุป-ออกหนังสือ ทำ PDF (มี QR ท้ายเอกสาร) แล้วให้เลือกเองว่าจะ 🖨️ พิมพ์ · 🔗 คัดลอกลิงก์ ส่งให้พนักงาน · หรือ ✉️ เมล ให้หัวหน้า
คำขอตกเบิกที่ช่อง "ขอโดย" = HR ถือว่าไม่ต้องออกเอกสาร ระบบไม่นำมาขึ้นคิว · ❌ = ต้องแก้ในชีตก่อน · ⚠️ = ออกได้แต่ควรดู · เลขที่เอกสารรันตอนกดออกเท่านั้น

🔎 ผลตรวจข้อมูลคำขอ

คำขอทั้งหมด — รอออกเอกสาร

ประเภทวันที่ขอรหัสชื่อ-สกุลรายละเอียดมีผล / วันงานผู้ขอ / หัวหน้าตรวจ
🗂️ เอกสารที่ออกไปแล้วทุกประเภท — ระบบทำ PDF เก็บใน Drive ให้ทุกฉบับ — ไม่ส่งอีเมลอัตโนมัติ กด ✉️ เมล เมื่อต้องการส่งให้หัวหน้า (เปิดส่งอัตโนมัติได้ในตั้งค่า) · กด ✉️ เมล เพื่อส่งซ้ำ · หัวหน้ากด "ส่งเอกสารกลับ" แล้วจะขึ้น ส่งกลับแล้ว พร้อมไฟล์แนบ · 🔗 คัดลอกลิงก์ คัดลอกข้อความ+ลิงก์ดาวน์โหลดส่งให้พนักงานพิมพ์เอง (มีในหน้า 👁️ ดู ด้วย) · ✏️ แก้ข้อความแล้วพิมพ์ซ้ำ (เลขที่เดิม) · ✖ ยกเลิก แล้วคำขอกลับเข้าคิว

เอกสารที่ออกแล้ว

เอกสารพนักงานPDF / เมลส่งกลับจัดการ
🚫 คำขอที่ถูก ยกเลิก ในชีต — ไม่ขึ้นในคิว ดูไว้เพื่อติดตาม · คำขอที่ยังไม่ approve จะอยู่ในคิวปกติพร้อมป้าย "รออนุมัติ"

คำขอที่ยกเลิก

ประเภทวันที่ขอรหัสชื่อ-สกุลรายละเอียดมีผล / วันงานผู้ขอ / หัวหน้าสถานะ
🎁 เงื่อนไขสวัสดิการอ่านสดจากแท็บ เงื่อนไขสวัสดิการ — แก้ในชีตแล้วกด ⟳ แอปจะใช้จำนวนเงินใหม่ทันที · เอกสารสวัสดิการเลือกเกณฑ์จากอายุงาน ณ วันที่จัดงาน
👥 หน้านี้แสดงเอกสารของ คุณเอง (ตกเบิก) และของ ลูกน้องในทีมคุณ — เปิด PDF พิมพ์ได้เลย เมื่อลงชื่อครบแล้วกด 📤 ส่งเอกสารกลับ แนบรูปถ่าย/ไฟล์ที่เซ็นแล้ว ระบบจับคู่กับเอกสารที่ HR ออกไว้ให้อัตโนมัติ
มีเอกสารในมือแต่ไม่อยู่ในรายการ? สแกน QR ท้ายเอกสาร ด้วยกล้องมือถือ หรือกดปุ่มด้านล่างแล้วกรอกเลขที่เอกสารเอง — ระบบจะอ่านเลขที่จากรูปที่แนบมาตรวจให้ว่าตรงกัน

เลขที่ประเภทออกเมื่อรหัสชื่อ-สกุลมีผล / วันงานสถานะ

🔗 การเชื่อมต่อหลังบ้าน

เปิดชีตคำขอ → ส่วนขยาย → Apps Script → วางไฟล์ rattana-hr-docs-apps-script-v2.4.gs → Run setupSheet() → Deploy → New deployment → Web app (Execute as: Me, Who has access: Anyone) → คัดลอก URL มาวางที่นี่

📝 ค่าเริ่มต้นบนเอกสาร

"งวดเงินเดือนรอบ": มีผลวันที่ 1–15 → เงินออกวันที่ 20 เดือนเดียวกัน · มีผลวันที่ 16–สิ้นเดือน → เงินออกวันที่ 5 เดือนถัดไป (ใช้กับ เงินเดือน · เบี้ยเลี้ยง · อื่นๆ) · ค่าตำแหน่ง/เบี้ยขยันพิเศษ · ค่าโทรศัพท์ · Incentive (ค่าคอม) คิดทั้งเดือนแล้วจ่ายวันที่ 20 ของเดือนถัดไป (มีผล 1/9 → งวด 20/10) · แก้รายใบได้ · รายได้รวมเทียบเป็นรายเดือนเสมอ — ค่าแรงรายวันฝั่ง "ก่อนปรับ" และ "เบี้ยเลี้ยง" คูณ 26 วันทำงาน · ค่าแรงรายวันฝั่ง "ปรับใหม่" คูณ 30 วัน (แก้ได้ที่ช่องด้านบน)

🔢 เลขที่เอกสาร

สวัสดิการใช้รูปแบบเดิมของบริษัท S.E.B.YYMM/NNN (ปี ค.ศ. 2 หลัก + เดือน / ลำดับต่อเนื่อง) · ปรับเงินเดือน SAYY-NNN (ปี พ.ศ. 2 หลัก ลำดับต่อเนื่องในปี) · เลขรันที่หลังบ้านตอนกดออกเอกสารเท่านั้น · ถ้าเคยออกเอกสารนอกระบบมาก่อน ให้ใส่ลำดับล่าสุดที่ใช้ไปแล้ว ระบบจะรันต่อจากนั้น

📊 แหล่งข้อมูล

ข้อมูลพนักงานใช้แท็บ ข้อมูลพนักงาน เป็นหลัก ช่องไหนว่างไล่ดู ข้อมูลPTT → เงินเดือน → นำเข้า-ข้อมูลพนักงาน → ทะเบียนผู้ใช้กลาง · เอกสารที่ออกเขียนลง สรุป-ออกหนังสือ และเลขที่เอกสารกลับไปที่แท็บ สวัสดิการ

🔐 สิทธิ์การใช้งาน

ผู้ใช้งาน: -
ออกเอกสารได้เฉพาะ แผนกทรัพยากรบุคคล (ตั้งที่หลังบ้าน ตัวแปร HR_DEPT / HR_EMAILS) · หัวหน้างานเห็นเฉพาะรายชื่อเอกสารของลูกน้องตัวเอง เปิด PDF และส่งเอกสารกลับได้ ไม่เห็นตัวเลขในระบบ · ข้อมูลทั้งหมดอ่านผ่านหลังบ้าน ชีตไม่ต้องเปิดแชร์สาธารณะ
