📌 ขั้นตอน — หัวหน้างานกรอกคำขอในชีต ขอปรับเงินเดือน และกด approve → รายการมาเข้าคิวที่นี่ → กด 👁️ ตรวจ/แก้ ดูตัวอย่างและปรับข้อความได้ → กด 🖨️ ออกเอกสาร ระบบบันทึกลงแท็บ สรุป-ออกหนังสือ แล้วเปิดหน้าพิมพ์ให้ทันที
"ก่อนปรับ" ดึงจากชีตเงินเดือน งวดล่าสุดก่อนวันที่มีผล · "ปรับใหม่" ดึงจากคำขอของหัวหน้างาน · ติ๊กหลายรายการแล้วกด ออกเอกสารที่เลือก เพื่อพิมพ์รวดเดียว

คำขอที่อนุมัติแล้ว — รอออกเอกสาร

วันที่ขอรหัสชื่อ-สกุลศูนย์ · ตำแหน่งประเภท ปรับใหม่มีผลหัวหน้างาน
📄 เอกสารที่ออกไปแล้ว — เมื่อหัวหน้างานได้เอกสารที่เซ็นครบ ให้กด ส่งเอกสารกลับ ในแอปนี้ (เห็นเฉพาะลูกน้องตัวเอง) รายการจะขึ้น ส่งกลับแล้ว พร้อมไฟล์แนบ · พิมพ์ซ้ำได้จากปุ่ม 🖨️ · ออกผิดให้กด ✖ ยกเลิก แล้วรายการจะกลับไปเข้าคิวใหม่

เอกสารที่ออกแล้ว

เลขที่ออกเมื่อรหัสชื่อ-สกุลศูนย์มีผล หัวหน้างานส่งกลับพิมพ์
⏳ คำขอที่ หัวหน้างานยังไม่กด approve หรือ ยกเลิก — ยังออกเอกสารไม่ได้ ดูไว้เพื่อติดตาม · ถ้าคำขอไหนข้อมูลผิดช่อง (เช่น พิมพ์ตัวหนังสือในช่องตัวเลข) จะมีเครื่องหมาย ⚠️ ให้แก้ในชีตก่อน

คำขอที่ยังไม่พร้อมออกเอกสาร

วันที่ขอรหัสชื่อ-สกุลประเภทปรับใหม่ มีผลหัวหน้างานสถานะ
👥 หน้านี้แสดงเฉพาะเอกสารของ ลูกน้องในทีมคุณ — เมื่อได้รับเอกสารที่ HR ออกให้และเซ็นครบแล้ว ให้กด 📤 ส่งเอกสารกลับ แนบรูปถ่าย/ไฟล์ที่เซ็นแล้ว ระบบจะจับคู่กับเอกสารที่ HR ออกไว้ให้อัตโนมัติ

เอกสารที่ HR ออกให้แล้ว

คำขอของทีมที่รอ HR ออกเอกสาร

วันที่ขอรหัสชื่อ-สกุลประเภทปรับใหม่มีผลสถานะคำขอ

🔗 การเชื่อมต่อหลังบ้าน

เปิดชีตคำขอปรับเงินเดือน → ส่วนขยาย → Apps Script → วางไฟล์ rattana-hr-docs-apps-script-v1.0.gs → Run setupSheet() → Deploy → New deployment → Web app (Execute as: Me, Who has access: Anyone) → คัดลอก URL มาวางที่นี่

📦 มีเอกสาร 0 รายการที่ออกไว้ตอนยังไม่ได้ต่อหลังบ้าน (เก็บในเครื่องนี้)

📝 ค่าเริ่มต้นบนเอกสาร

"งวดเงินเดือนรอบ" คำนวณจากวันที่มีผล: มีผลวันที่ 1–15 → จ่ายวันที่ 20 เดือนเดียวกัน · มีผลวันที่ 16 ขึ้นไป → จ่ายวันที่ 5 เดือนถัดไป · Incentive → วันที่ 20 เดือนถัดไป (แก้รายใบได้ในหน้าตรวจ/แก้)

🔐 สิทธิ์ฝ่ายบุคคล

ผู้ที่เห็นคำขอทั้งหมดและออกเอกสารได้ = แผนก ทรัพยากรบุคคล ในทะเบียนผู้ใช้กลาง หรือ Role ≥ 7 หรืออีเมลในรายการนี้ (คั่นด้วยเครื่องหมายจุลภาค) · คนอื่นที่ล็อกอินจะเห็นเฉพาะเอกสารของลูกน้องตัวเอง

📊 แหล่งข้อมูล

คำขอ (อ่าน): ชีต ขอปรับเงินเดือน — หัวหน้างานกรอก + สถานะ approve
เงินเดือนปัจจุบัน (อ่าน): แท็บ เงินเดือน รายงวด — ใช้เป็นค่า "ก่อนปรับ"
ทะเบียนพนักงาน (อ่าน): ทะเบียนผู้ใช้กลาง + แท็บ นำเข้า-ข้อมูลพนักงาน — ตำแหน่ง, BU, วันเริ่มงาน, หัวหน้างาน
เอกสารที่ออก (เขียน): แท็บ สรุป-ออกหนังสือ ผ่าน Apps Script
