📌 3 ขั้น — ① หัวหน้างานกรอกคำขอในชีต (แท็บ ขอปรับเงินเดือน / สวัสดิการ) — ขึ้นคิวทันทีไม่ต้องรอ approve (มีป้ายสถานะบอก) → ② กด 👁️ ตรวจ & ออกเอกสาร ระบบตรวจข้อมูลให้ (✅ ⚠️ ❌) พร้อมตัวอย่างเอกสาร → ③ กด ✔ ออกเอกสาร & พิมพ์ ระบบรันเลขที่ บันทึกลงแท็บ สรุป-ออกหนังสือ ทำ PDF ส่งเมลหัวหน้า แล้วเปิดหน้าพิมพ์
❌ = ต้องแก้ในชีตก่อน · ⚠️ = ออกได้แต่ควรดู · เลขที่เอกสารรันตอนกดออกเท่านั้น

🔎 ผลตรวจข้อมูลคำขอ

คำขอทั้งหมด — รอออกเอกสาร

ประเภทวันที่ขอรหัสชื่อ-สกุลรายละเอียดมีผล / วันงานผู้ขอ / หัวหน้าตรวจ
🗂️ เอกสารที่ออกไปแล้วทุกประเภท — ระบบทำ PDF เก็บใน Drive และส่งอีเมลให้หัวหน้างานอัตโนมัติ (ปิดได้ในตั้งค่า) · กด ✉️ เมล เพื่อส่งซ้ำ · หัวหน้ากด "ส่งเอกสารกลับ" แล้วจะขึ้น ส่งกลับแล้ว พร้อมไฟล์แนบ · ✏️ แก้ข้อความแล้วพิมพ์ซ้ำ (เลขที่เดิม) · ✖ ยกเลิก แล้วคำขอกลับเข้าคิว

เอกสารที่ออกแล้ว

เลขที่ประเภทออกเมื่อรหัสชื่อ-สกุลมีผล / วันงาน ผู้ขอ / หัวหน้าPDF / เมลส่งกลับ
🚫 คำขอที่ถูก ยกเลิก ในชีต — ไม่ขึ้นในคิว ดูไว้เพื่อติดตาม · คำขอที่ยังไม่ approve จะอยู่ในคิวปกติพร้อมป้าย "รออนุมัติ"

คำขอที่ยกเลิก

ประเภทวันที่ขอรหัสชื่อ-สกุลรายละเอียดมีผล / วันงานผู้ขอ / หัวหน้าสถานะ
🎁 เงื่อนไขสวัสดิการอ่านสดจากแท็บ เงื่อนไขสวัสดิการ — แก้ในชีตแล้วกด ⟳ แอปจะใช้จำนวนเงินใหม่ทันที · เอกสารสวัสดิการเลือกเกณฑ์จากอายุงาน ณ วันที่จัดงาน
👥 หน้านี้แสดงเฉพาะเอกสารของ ลูกน้องในทีมคุณ — เปิด PDF พิมพ์ได้เลย เมื่อแจ้งพนักงานและลงชื่อครบแล้ว ให้กด 📤 ส่งเอกสารกลับ แนบรูปถ่าย/ไฟล์ที่เซ็นแล้ว ระบบจะจับคู่กับเอกสารที่ HR ออกไว้ให้อัตโนมัติ

เอกสารที่ HR ออกให้แล้ว

เลขที่ประเภทออกเมื่อรหัสชื่อ-สกุลมีผล / วันงานสถานะ

🔗 การเชื่อมต่อหลังบ้าน

เปิดชีตคำขอ → ส่วนขยาย → Apps Script → วางไฟล์ rattana-hr-docs-apps-script-v2.3.gs → Run setupSheet() → Deploy → New deployment → Web app (Execute as: Me, Who has access: Anyone) → คัดลอก URL มาวางที่นี่

📝 ค่าเริ่มต้นบนเอกสาร

"งวดเงินเดือนรอบ": มีผลวันที่ 1–15 → เงินออกวันที่ 20 เดือนเดียวกัน · มีผลวันที่ 16–สิ้นเดือน → เงินออกวันที่ 5 เดือนถัดไป · Incentive → วันที่ 20 เดือนถัดไป (แก้รายใบได้) · รายได้รวมเทียบเป็นรายเดือนเสมอ (รายวัน × วันทำงานต่อเดือน)

🔢 เลขที่เอกสาร

สวัสดิการใช้รูปแบบเดิมของบริษัท S.E.B.YYMM/NNN (ปี ค.ศ. 2 หลัก + เดือน / ลำดับต่อเนื่อง) · ปรับเงินเดือน SAYY-NNN (ปี พ.ศ. 2 หลัก ลำดับต่อเนื่องในปี) · เลขรันที่หลังบ้านตอนกดออกเอกสารเท่านั้น · ถ้าเคยออกเอกสารนอกระบบมาก่อน ให้ใส่ลำดับล่าสุดที่ใช้ไปแล้ว ระบบจะรันต่อจากนั้น

📊 แหล่งข้อมูล

ข้อมูลพนักงานใช้แท็บ ข้อมูลพนักงาน เป็นหลัก ช่องไหนว่างไล่ดู ข้อมูลPTT → เงินเดือน → นำเข้า-ข้อมูลพนักงาน → ทะเบียนผู้ใช้กลาง · เอกสารที่ออกเขียนลง สรุป-ออกหนังสือ และเลขที่เอกสารกลับไปที่แท็บ สวัสดิการ

ออกเอกสารได้เฉพาะ แผนกทรัพยากรบุคคล (ตั้งที่หลังบ้าน ตัวแปร HR_DEPT / HR_EMAILS) · หัวหน้างานเห็นเฉพาะรายชื่อเอกสารของลูกน้องตัวเอง เปิด PDF และส่งเอกสารกลับได้ ไม่เห็นตัวเลขในระบบ · ข้อมูลทั้งหมดอ่านผ่านหลังบ้าน ชีตไม่ต้องเปิดแชร์สาธารณะ
