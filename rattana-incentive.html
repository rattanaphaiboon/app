ประวัติ Incentive รายบุคคล —

    เลือกพนักงานเพื่อดูประวัติ Incentive ย้อนหลัง

    หลักเกณฑ์การคำนวณ Incentive ใหม่

    อ่านจากชีต "ชีทนก หลักเกณฑ์การคำนวณ Incentive ใหม่"
    % ผลงานเทียบเป้าเกณฑ์เดิมเกณฑ์ใหม่
    ต่ำกว่า 80%0 บาท0 บาท
    80% – 99.99%0 บาทIncentive × % ผลงาน
    100% ขึ้นไปIncentive เต็มจำนวนIncentive เต็มจำนวน (ห้ามจ่ายเกิน)
    เกณฑ์ใหม่: ถ้า Achievement < 80% → Incentive = 0 ถ้า 80% ≤ Achievement < 100% → Incentive = Target Incentive × Achievement ถ้า Achievement ≥ 100% → Incentive = Target Incentive (ห้ามจ่ายเกิน) ตัวอย่าง: เป้า Incentive 15,000 บาท ผลงาน 80% → ได้ 12,000 บาท เป้า Incentive 3,000 บาท ผลงาน 85% → ได้ 2,550 บาท

    หัวข้อเป้าแบบพิเศษ (คอลัมน์ "วัดผล" จากแท็บ Pattern Incentive)

    วัดผลเกณฑ์เดิมเกณฑ์ใหม่ในแอปนี้
    ว่าง (หัวข้อทั่วไป)ตามตารางด้านบนตามตารางด้านบน
    100% (KPI ผ่าน/ไม่ผ่าน)ถึง 100% ได้เต็ม ไม่ถึงได้ 0ใช้เกณฑ์ใหม่เหมือนหัวข้อทั่วไป
    <100% (ยิ่งน้อยยิ่งดี เช่น ลูกหนี้)ต่ำกว่าเป้าได้เต็มเหมือนเดิม (กลับด้าน คิดสัดส่วนไม่ได้)
    % (ขั้นบันได ต่อทุก 100,000 บาท)ถึง 100% ได้ตามขั้นของเป้า ไม่ถึงได้ 0วงเงินที่ 100% × % ผลงาน (ต่ำกว่า 80% = 0 · สูงสุด 100%)

    * เกณฑ์เดิม = จ่ายเฉพาะรายการที่ทำได้ 100% ขึ้นไป · เกณฑ์ใหม่จึงจ่ายเท่าหรือมากกว่าเดิมทุกรายการ · แอปอ่านข้อมูลอย่างเดียว ไม่เขียนกลับชีต
